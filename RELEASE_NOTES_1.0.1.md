## DesharpCore 1.0.1

### What's new
- **Acknowledgements:** the README now credits the original Desharp utility by tomFlidr, which DesharpCore is a fork of, updated to work with ASP.NET Core 10.
- **ExampleTodoMVC:** added a sample ASP.NET Core 10 MVC todo app that shows DesharpCore working end to end. It covers dumps, logs, timers, assertions, exception handling, the debug panels and the `/Debug` feature pages. See the "Example Todo MVC Application" section of the README.

### Notes
- There are no breaking changes and no API changes in this release.
- Install from nuget.org: `dotnet add package DesharpCore --version 1.0.1`
- Requires .NET 10 or later. For web apps it needs ASP.NET Core MVC or Razor Pages.

**Full changelog:** https://github.com/rsobrepena/desharpcore/compare/v1.0.0...v1.0.1
